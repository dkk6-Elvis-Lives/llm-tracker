About this tracker

A living inventory of large language models from the major frontier and open-weights vendors, covering 2023 through the current refresh date. Every non-trivial field links to the source page it was verified from.

How to use it

  • Lineage — one column per vendor, oldest to newest, so you can see how each vendor's family tree has evolved (e.g. Anthropic: Claude 2 → Claude 3 → 3.5 → 4 → 4.5 → 5). Toggle the chips to include superseded or deprecated models.
  • Compare — sortable and filterable table for "what should I use for X?" questions. Filter by vendor, tier, openness, modality, minimum context window, or price cap. Click any column header to sort.
  • Detail — click any model in either view to open a card with pricing, context, positioning, and links back to the vendor's own source pages.

Fields explained

  • Tier — the vendor's positioning slot: Frontier / flagship, Balanced / mid, Fast / small, Reasoning-optimized, Coding-specialized, Vision-specialized, Nano / on-device.
  • Status — current (still recommended), superseded (replaced by a newer version), deprecated (formal sunset date announced), legacy (kept for compatibility only).
  • Openness — Closed API vs. Open weights. The specific license (Apache 2.0, MIT, Llama license, etc.) appears in the detail view.
  • Context window — max input tokens per the vendor's own model card / API docs.
  • Price — USD per 1M tokens on the vendor's own primary API at standard tier. Batch discounts, cached-input pricing, and prompt caching are not reflected. For open-weights models without a first-party API, a representative host's price may be shown (noted in the source link).

Refreshing the data

Ask "refresh the LLM tracker" (or "update the LLM tracker") in this project and a live research pass will run against vendor announcement and pricing pages, diff against the current data, and show additions/changes/deprecations before writing anything.

Data files

The tracker reads from models.json alongside this page. The full research markdown with every source link is at llm_inventory_YYYY-MM-DD.md.
